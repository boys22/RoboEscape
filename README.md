# RoboEscape (b1.2.0)

RoboEscape는 고장 난 공장을 탈출하는 로봇 로그라이크예요. 브라우저만 있으면 PC와 휴대폰에서 바로 플레이할 수 있어요.

폐기장 → 조립 라인 → 품질 검사실, 3개 구역(총 21개 방)을 지나 최종 보스 QC-9를 쓰러뜨리면 공장을 탈출해요. 판마다 맵과 보상이 무작위로 바뀌고, 영구 성장은 없어요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성. `style.css`와 `game.min.js`를 불러와요 |
| `style.css` | 디자인(색, 배치, 모바일 화면) |
| `game.min.js` | 실제로 실행되는 게임 코드 (압축본) |
| `game.js` | 읽기 쉬운 원본 코드. 수정하거나 오류를 찾을 때 봐요 (실행엔 안 쓰여요) |
| `assets/` | 홈 화면 아이콘, 탭 아이콘, 공유 미리보기 이미지 |
| `manifest.webmanifest` | 홈 화면에 추가했을 때 앱처럼 열리게 하는 설정 (가로 · 전체 화면) |

`supabase/leaderboard.sql`은 순위 서버(Supabase)에 한 번만 실행하는 설정 파일이에요(아래 '순위표' 참고).

네 파일은 **항상 같은 폴더**에 있어야 해요. 컴퓨터에서 `index.html`을 더블클릭해도 바로 실행돼요.

## 조작

| 동작 | PC | 모바일 (가로 화면) |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 패널(화면 왼쪽 절반 어디든)에 엄지를 대고 끌기 |
| 기본 공격 | J (또는 좌클릭) | 공격 버튼 (무기에 따라 공격·사격·분사) |
| 점프 → 내려찍기 | K → 공중에서 J | 점프 → 공중에서 공격 |
| 특수 공격 | L (또는 우클릭) | 특수 버튼 (투척·산탄·불길) |
| 대시 | Space | 대시 버튼 |
| 일시정지 / 시작 화면으로 | Esc | 오른쪽 패널의 일시정지 버튼 |
| 전체 화면 | F | 시작 시 자동, 화면 위 버튼으로 전환 |

조준은 자동이에요. 강철 렌치는 이동 방향에 가까운 적을 노리고, 리벳건과 용접 토치는 공격을 시작할 때 가장 가까운 적을 표적으로 고정해요.

시작 화면에서 로봇 5종과 무기 3종(강철 렌치, 리벳건, 용접 토치)을 골라요. 로봇은 모습만 다르고, 무기는 싸우는 방식이 달라요.

## GitHub Pages로 올리기 (휴대폰에서 보기)

명령어 없이 GitHub 웹사이트에서만 할 수 있어요.

1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**를 눌러요.
2. 저장소 이름을 정해요. 예: `RoboEscape`
3. **Public**을 선택하고 **Create repository**를 눌러요. 무료 계정은 Public이어야 Pages를 쓸 수 있어요.
4. 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 눌러요.
5. 이 폴더 안의 **파일과 폴더를 전부**(assets, supabase 폴더 포함) 끌어다 놓고, 메시지에 `b1.2.0`이라고 적은 뒤 **Commit changes**를 눌러요.
6. 저장소 **Settings → Pages**로 가서 아래처럼 설정하고 **Save**를 눌러요.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/ (root)**
7. 1~2분 뒤 Pages 화면 위쪽에 주소가 나타나요. 형식은 아래와 같아요.

   ```
   https://<GitHub 아이디>.github.io/RoboEscape/
   ```

8. 휴대폰에서 이 주소를 열고 **가로로** 들면 플레이할 수 있어요.

### 새 버전으로 바꿀 때

새 버전 폴더의 파일을 같은 방식으로 올리면 같은 이름의 파일이 덮어써져요. `index.html`이 `game.min.js?v=버전` 형식으로 불러와서, 휴대폰 브라우저도 예전 파일 대신 새 파일을 받아요.

### 전체 화면으로 하기

안드로이드는 시작하기를 누르면 자동으로 전체 화면이 돼요. 아이폰 Safari는 웹페이지 전체 화면을 지원하지 않아서, 아래처럼 홈 화면에 추가해서 여는 게 가장 넓게 보여요.

### 홈 화면에 추가하면 더 편해요

- **아이폰 (Safari):** 공유 버튼 → **홈 화면에 추가**
- **안드로이드 (Chrome):** 메뉴(⋮) → **홈 화면에 추가**

홈 화면 아이콘으로 열면 주소창 없이 화면을 더 넓게 써요.

### 버전 태그 남기기 (선택)

저장소 오른쪽의 **Releases → Create a new release**에서 태그 이름을 `b1.2.0`로 만들어 두면, 나중에 이 버전으로 되돌아가기 쉬워요.

## 순위표 (Supabase)

- 시작 화면의 **순위**, 결과 화면의 **순위 보기**로 TOP 20을 볼 수 있어요. 총점 순이고, 동점이면 시간이 짧은 쪽이 위예요. 닉네임마다 최고 기록 1개만 남아요.
- 판이 끝나면 결과 화면에서 닉네임(1~12자)을 적고 **기록 등록**을 누르면 돼요. 닉네임은 그 브라우저에 기억돼요.
- 테스트 버튼으로 시작한 판은 등록되지 않아요.
- 기록은 서버 함수가 검사한 뒤에만 저장돼요(판 토큰 1회용, 방당 최소 8초, 점수 상한, 탈출은 방 21 도달 시만).

### 처음 한 번만: 서버 설정
1. Supabase 대시보드 → **SQL Editor** → `supabase/leaderboard.sql` 내용을 붙여 넣고 **Run**.
2. 게임 코드(`game.js`/`game.min.js`)에는 프로젝트 주소와 **공개 키(publishable key)**가 들어 있어요. 공개용 키라 노출돼도 괜찮아요. 비밀 키(secret / service_role)는 절대 코드에 넣지 마세요.

### 관리
- 수상한 기록 지우기: Supabase → **Table Editor → re_scores** → 그 줄 삭제.
- 무료 요금제는 일주일 동안 접속이 없으면 프로젝트가 잠들어요. 대시보드에서 **Restore**를 누르면 데이터 그대로 다시 켜져요.
- claude.ai 미리보기 링크에서는 외부 연결이 막혀 순위가 안 보일 수 있어요. GitHub Pages 주소에서 이용하세요.

## 설정과 숨은 메뉴

- **소리 설정:** 게임 중 일시정지(Esc 또는 일시정지 버튼)에서 효과음·배경음 볼륨과 진동을 바꿀 수 있어요. 그 브라우저에 기억돼요. M 키는 전체 소리 켜기/끄기예요.
- **배경음:** 시작 화면, 구역 3곳, 보스 3마리, 엔딩마다 다른 곡이 나와요. 외부 음원 없이 브라우저에서 실시간으로 만들어요.
- **개발자 메뉴:** 시작 화면 아래 **버전 글자를 2초 안에 5번** 누르면 테스트 버튼(1구역 보스 · 2구역 · 2구역 보스 · 3구역 · 최종 보스)이 나타나요. 다시 5번 누르면 숨겨져요. 테스트 판은 순위에 등록되지 않아요.

## 공유 미리보기 (카카오톡·슬랙 등)

`index.html`의 `og:image`가 `assets/og-image.png`(상대 주소)로 되어 있어요. 메신저 미리보기는 전체 주소가 필요해서, GitHub Pages 주소가 정해지면 아래처럼 바꾸면 이미지가 떠요.

```html
<meta property="og:image" content="https://<아이디>.github.io/RoboEscape/assets/og-image.png">
```
