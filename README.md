# RoboEscape (b0.4.1)

RoboEscape는 고장 난 공장을 탈출하는 로봇 로그라이크예요. 브라우저만 있으면 PC와 휴대폰에서 바로 플레이할 수 있어요. 파일은 `index.html` 하나뿐이에요.

## 조작

| 동작 | PC | 모바일 (가로 화면) |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 패널(화면 왼쪽 절반 어디든)에 엄지를 대고 끌기 |
| 기본 공격 | J (또는 좌클릭) | 공격 버튼 (무기에 따라 공격·사격·분사) |
| 점프 → 내려찍기 | K → 공중에서 J | 점프 → 공중에서 공격 |
| 특수 공격 | L (또는 우클릭) | 특수 버튼 (투척·산탄·불길) |
| 대시 | Space | 대시 버튼 |
| 일시정지 / 시작 화면으로 | Esc | 오른쪽 패널의 일시정지 버튼 |
| 전체 화면 | F | 시작 시 자동, 화면 위 버튼으로 전환 |

조준은 자동이에요. 강철 렌치는 이동 방향에 가까운 적을 노리고, 리벳건과 용접 토치는 공격을 시작할 때 가장 가까운 적을 표적으로 고정해요.

시작 화면에서 로봇 5종과 무기 3종(강철 렌치, 리벳건, 용접 토치)을 골라요. 로봇은 모습만 다르고, 무기는 싸우는 방식이 달라요.

## GitHub Pages로 올리기 (휴대폰에서 보기)

명령어 없이 GitHub 웹사이트에서만 할 수 있어요.

1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**를 눌러요.
2. 저장소 이름을 정해요. 예: `RoboEscape`
3. **Public**을 선택하고 **Create repository**를 눌러요. 무료 계정은 Public이어야 Pages를 쓸 수 있어요.
4. 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 눌러요.
5. 이 폴더의 `index.html`, `README.md`, `CHANGELOG.md`를 끌어다 놓고, 메시지에 `b0.4.1`이라고 적은 뒤 **Commit changes**를 눌러요.
6. 저장소 **Settings → Pages**로 가서 아래처럼 설정하고 **Save**를 눌러요.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/ (root)**
7. 1~2분 뒤 Pages 화면 위쪽에 주소가 나타나요. 형식은 아래와 같아요.

   ```
   https://<GitHub 아이디>.github.io/RoboEscape/
   ```

8. 휴대폰에서 이 주소를 열고 **가로로** 들면 플레이할 수 있어요.

### 전체 화면으로 하기

안드로이드는 시작하기를 누르면 자동으로 전체 화면이 돼요. 아이폰 Safari는 웹페이지 전체 화면을 지원하지 않아서, 아래처럼 홈 화면에 추가해서 여는 게 가장 넓게 보여요.

### 홈 화면에 추가하면 더 편해요

- **아이폰 (Safari):** 공유 버튼 → **홈 화면에 추가**
- **안드로이드 (Chrome):** 메뉴(⋮) → **홈 화면에 추가**

홈 화면 아이콘으로 열면 주소창 없이 화면을 더 넓게 써요.

### 버전 태그 남기기 (선택)

저장소 오른쪽의 **Releases → Create a new release**에서 태그 이름을 `b0.4.1`로 만들어 두면, 나중에 이 버전으로 되돌아가기 쉬워요.
